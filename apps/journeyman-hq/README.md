# Journeyman HQ

Roy's Maryland Journeyman Electrician exam-prep app — NEC 2020, PSI format (70 questions · 210 minutes · 70% to pass).
Static frontend, zero backend calls, no secrets. Lives behind the apps vault at `https://apps.daroyperkins.com/journeyman-hq/`.

## What's in it
- **Home** — countdown to the PSI exam date (set on first run, editable in More), study streak, cards due, last sim score, plan %, weakest topics, recent attempts.
- **Cards** — topic decks + "everything due". SM-2-lite spaced repetition: *Needs work* (back in 10 min and again at the end of the session), *Got it*, *Easy*. Button labels preview the next interval.
- **Exam** — full simulation (70 Qs, 210-min timer, flag-for-review, review grid, submit with unanswered = wrong, auto-submit at time) and a 10-question untimed **quick drill** biased to weak topics and previously missed questions. Results: verdict, score, per-topic breakdown, missed questions with explanations. Attempt history persists. An attempt in progress survives a refresh or a closed tab (time keeps counting on sims).
- **Plan** — 30-day checklist mapped to topics and NEC articles, progress ring. Day 30 pins to the exam date when one is set.
- **More** — add your own flashcard or 4-choice question (merged into decks/drills immediately), export my content as JSON (for merging into a future bank), full backup/restore, bank manifest (which versions are live), settings, reset.

## How it gets its information
- Content ships in the bundle as versioned JSON banks: `data/questions-v1.json`, `data/flashcards-v1.json`, `data/plan-v1.json`, with `data/manifest.json` listing versions and counts. Every item carries `topic`, `article` (NEC 2020 reference), `difficulty` 1–3, `source`; uncertain items carry `review: true` + `note`.
- Three ongoing feeds: (a) Roy adds cards/questions in-app → stored in this browser → **Export my content** produces JSON for the next bank; (b) new packs ship as `data/questions-v2.json` etc. plus an updated manifest through the same zip upload; (c) the app's own loop — missed questions are weighted back into drills and sims, practice results drive the weak-topic list, SRS schedules reviews from performance.
- Copyright rail: the NEC is NFPA-copyrighted. Banks paraphrase concepts and cite article numbers; they never reproduce Code text.

## Build / preview / deploy
```bash
cd apps/journeyman-hq
./build.sh                       # → dist/journeyman-hq-v1.0.0.zip (index.html at top level)
python3 -m http.server 8080      # preview at http://localhost:8080/ (file:// blocks fetch of data/*.json)
```
Deploy = Roy uploads the zip at `https://apps.daroyperkins.com/upload/` with the name `journeyman-hq` (re-upload replaces the app; local progress is in the browser, not the bundle, so it survives). No deploy is done from this repo.

## Adding content (v2 pack)
1. Add items to `content/questions/<topic>.json` or `content/flashcards/<topic>.json` (or paste Roy's exported custom items in, giving them bank IDs).
2. Bump `banks.*.version` and `file` names in `content/manifest.src.json`, then `./build.sh`. The validator rejects bad topics, missing articles, wrong choice counts, duplicate IDs, and "all of the above" choices.
3. Luigi samples flagged + new items against the book; clear `review` flags once verified and set `reviewed` dates in the manifest.
